# AxPhone — installation par QR code

[Télécharger le dernier APK](https://github.com/equipe-51/axphone-releases/releases/latest/download/axphone.apk)

![QR code d'installation d'AxPhone](provisioning-qr.png)

Ce QR code est valable pour toutes les versions : il pointe vers la dernière release.

Sur un téléphone **réinitialisé, sans compte Google** :
1. sur le premier écran (« Bienvenue »), toucher **6 fois** au même endroit : le lecteur de QR code s'ouvre ;
2. se connecter au Wi-Fi, puis scanner ce QR code ;
3. accepter : Android télécharge AxPhone, en fait l'administrateur de l'appareil puis termine la configuration ;
4. dans AxPhone Réglages, toucher la bannière « ne peut pas mesurer ton temps d'écran » et autoriser AxPhone.
